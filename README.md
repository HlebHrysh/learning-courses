## 💻 How to Open in PyCharm

1. Open **PyCharm** (Community or Professional).
2. Go to **My Courses** ➔ click **"Open course from disk"** (or `File` ➔ `Learn and Teach` ➔ `Import Local Course...`).
3. Select either `.zip` archive from this folder.
4. Read the task theory on the right panel, write your code, and click the green **Check** button to run automated tests.

---

## 🔄 How to Sync to Another PC

On your second computer, simply run:
```bash
git clone https://github.com/HlebHrysh/learning-courses.git
cd learning-courses
```

Whenever new modules or updates are pushed, just run:
```bash
git pull
```

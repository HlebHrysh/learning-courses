# Завдання 3.1: Архітектура Telegram-бота та маршрутизація команд

У Telegram-ботах кожна дія користувача — це повідомлення або подія (`Update`).  
Бот аналізує вхідний текст та передає його у відповідний обробник (Handler).

### 🎯 Ваше завдання:
Реалізуйте роутер команд `dispatch_telegram_message(command: str, user_name: str) -> str`:
1. Якщо `command == "/start"`:  
   поверніть: `f"Вітаю, {user_name}! Я ваш навчальний бот-асистент."`
2. Якщо `command == "/help"`:  
   поверніть: `"Доступні команди: /start, /help, /weather, /rates"`
3. Якщо `command == "/weather"`:  
   поверніть: `"Для отримання погоди введіть назву міста."`
4. Для будь-якої іншої невідомої команди або тексту:  
   поверніть: `"Невідома команда. Натисніть /help для списку підказок."`

# Завдання 1.1: Робота з .gitignore та конфіденційними даними

У реальній розробці одна з головних помилок новачка — закоммітити в публічний GitHub репозиторій файл `.env` із паролями, секретними токенами або сміттєві кеш-файли `__pycache__` та віртуальне оточення `venv/`.

### 📚 Теорія:
* `.gitignore` — текстовий файл у корені проєкту, який вказує Git, які файли та папки **ігнорувати** (не відстежувати та не додавати в комміти).
* Приклади правил:
  * `*.pyc` — ігнорує всі файли з розширенням `.pyc`.
  * `__pycache__/` — ігнорує всю директорію кешу Python.
  * `.env` — ігнорує файл зі змінними оточення (паролі, токени).
  * `venv/` — ігнорує локальне віртуальне оточення.

1. Вона має завжди повертати список обов'язкових папок та шаблонів для Python-проєкту:
   * `"__pycache__/"`
   * `"*.pyc"`
   * `"venv/"`
   * `".pytest_cache/"`
2. Якщо аргумент `include_env=True`, функція повинна також додати у список рядок `".env"`.
3. Поверніть список правил.
